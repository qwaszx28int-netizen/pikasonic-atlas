# 发现作品与音乐历程

网站围绕已收录的 PIKASONIC 作品提供检索、导听与发现功能。当前目录是多个公开平台信息的合并快照，可能受到地区、版本、署名、下架及接口可访问范围影响；功能说明不代表已经核实艺人的完整作品史。

## 热门排序与本站投票

默认热门顺序参考网易云音乐艺人热歌列表，按已核对的歌曲对应关系应用到本站目录。它表示**最近同步的外部列表顺序**，不是歌曲播放次数、实时热度数值，也不是本站编辑手工编出的热度。平台没有披露或本站未取得的数据，不以猜测补齐。

没有匹配到该列表的作品仍保留在目录中。没有热门名次不等于没有人气，可能只是该平台未收录、曲名不同或版本尚未核对。可以用搜索、年份、曲风和其他排序继续寻找。

「心动排行榜」另由本站 Node.js / SQLite 后端保存的共享投票生成，展示有票作品的 Top 10。每个浏览器身份对每首最多一票，可撤回；浏览器身份不等于真人身份。外部热歌顺序与本站投票分别计算，互不充当对方的数据来源。GitHub Pages 静态部署可以浏览外部快照，不能独立提供共享投票。

更新外部信息可运行 `npm run sync:netease`，完成后审查匹配关系和快照变化，再构建发布。更新不会把网易云热歌名次换算为虚构的播放量。

## 按年份浏览音乐历程

「音乐历程」按**本站已收录作品的公开年份**组织条目，帮助浏览不同年份的作品和发行版本。年份以保存的来源元数据为依据；上传、重发行和最初公开可能发生在不同年份，因此时间线不能直接解释为作品的首次创作年份。

日期未知的作品归入「年份待核实」，不根据视频相对上传时间、专辑封面或作品气质推算年份。时间线是已收录资料的浏览方式，不是未经验证的完整生涯年表，也不据此推断艺术家的阶段、经历或创作意图。

## 随机发现与歌曲分享

歌曲目录工具栏的随机发现，会从当前搜索、年份、曲风及收藏等筛选结果中打开一首作品的导听。存在多个候选时，连续点击尽量不重复上一首；没有结果时按钮禁用。随机选择不代表热门排名或编辑评价，也不自动播放歌曲。

歌曲详情中的「分享歌曲」会复制当前站点的 URL，以 `?track=` 参数保存目录中的稳定曲目 ID，兼容 GitHub Pages 的项目子路径。打开链接会自动进入对应作品的详情；ID 不存在时显示提示。

分享的是公开曲目入口，不包含浏览器收藏、投票 Cookie 或个人偏好；打开链接不会替访问者投票。网站迁移到新域名或路径后，旧地址是否可用取决于部署者是否保留跳转。

歌曲详情提供网易云音乐与 YouTube 外链。已核实的记录显示精确直达；未核实时明确提供平台内搜索。搜索可能出现同名或其他版本，收听前请确认艺人和版本。本站不播放或托管歌曲音频、音乐视频或完整歌词。

目录修正、曲风依据、版本信息和平台链接问题，均可通过部署者实际维护的 GitHub 仓库反馈。原始来源与编辑导听应分别核查，不能把开放式聆听建议当作艺术家的创作自述。
